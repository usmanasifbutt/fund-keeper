Daily tracker · Google Sheets + Apps Script

Keeper

Every evening a script in your own Google account reads MUFAP's NAV table, works out your profit or loss, and sends you an email and a WhatsApp message. You keep your units up to date in a phone-friendly form. No logins to the MCB or Meezan apps, nothing to pay.

How it runs

  1. Wake upA time trigger in Apps Script starts the job around 9 pm Pakistan time, with a 9 am retry in case MUFAP publishes late.
  2. Read NAVsDownloads MUFAP's daily NAV page and refreshes all 558 funds in the Funds sheet, which also feeds the form's search.
  3. Load holdingsReads your units and amount invested from the Holdings sheet, which the form writes to.
  4. CalculateDay P/L = units × (NAV − previous NAV). Value = units × repurchase price. Your funds' NAVs are kept in the NAVs sheet.
  5. SendAn HTML email with a table and chart, plus a short WhatsApp text. If none of your funds has a new NAV date, it sends nothing.

Keeping your units up to date

A form only you can open, bookmarked on your phone. It opens with your current holdings filled in: change a number, add or remove a fund, press Save. Try the demo form.

  • Bought more: add the new units to the existing number, and the amount paid to "Invested".
  • New fund: press + Add fund and search by name, fund company or category.
  • Sold everything: press Remove.
  • Dividend paid as units: add the units and leave "Invested" alone. Skipping this shows a false loss, because the NAV drops on the payout day.

Every save is logged in the History sheet, so you can see what changed and when.

Reading MUFAP

The NAV page is a plain HTML table (id="table_id"), so the script reads it directly. Each fund has a stable MUFAP ID, which is what your holdings are linked to. Tested against the 13 Oct page: 558 funds found.

function parseMufap(html) {
  const table = html.slice(html.indexOf('id="table_id"'), html.indexOf('</table>'));
  return table.split(/<tr\b/i).slice(1).map(row => {
    const id = row.match(/FundID=(\d+)/)[1];
    const cells = [...row.matchAll(/<td\b[^>]*>([\s\S]*?)<\/td>/gi)].map(m => cleanText_(m[1]));
    return { id, amc: cells[1], name: cells[2], category: cells[3],
             repurchase: num_(cells[6]), nav: num_(cells[7]), date: isoFromMufap_(cells[8]) };
  });
}  // simplified; the real version skips bad rows and makes pension sub-fund names unique
